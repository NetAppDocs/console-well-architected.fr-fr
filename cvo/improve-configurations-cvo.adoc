= Mettre en œuvre des configurations système Cloud Volumes ONTAP bien architecturées
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp vous aide à mettre en œuvre les meilleures pratiques pour vos systèmes Cloud Volumes ONTAP exécutés sur le stockage Microsoft Azure grâce à des analyses de configuration et des recommandations. Vous pouvez examiner l’état de l’architecture, identifier les problèmes liés à vos configurations et obtenir des recommandations pour améliorer l’architecture des systèmes qui ne sont pas optimisés pour la fiabilité, la sécurité, l’efficacité, la performance et le coût.

Vous pouvez également ignorer l'analyse des configurations de stockage spécifiques qui ne s'appliquent pas à votre environnement de stockage afin d'éviter les alertes inutiles et des résultats d'optimisation inexacts.

link:configuration-analysis-cvo.html["Découvrez l'analyse de configuration et l'état bien architecturé."]



[[about-this-task]]
== À propos de cette tâche

Workload Factory analyse chaque jour les configurations système Cloud Volumes ONTAP sur Microsoft Azure. L’analyse quotidienne fournit l’état bien architecturé, des informations clés et des recommandations. Vous pouvez corriger automatiquement les problèmes de configuration afin de respecter les bonnes pratiques.

La connectivité via l'agent Link ou Console permet à NetApp Workload Factory d'effectuer une analyse complète de vos systèmes Cloud Volumes ONTAP afin de détecter les problèmes de performance, de protection des données et de configuration. Cela garantit que vous recevez des informations et des recommandations précises pour optimiser vos systèmes Cloud Volumes ONTAP.

Les exigences de configuration du stockage varient. Vous pouvez ignorer l'analyse des configurations qui ne s'appliquent pas à votre environnement de stockage. Ignorer les configurations qui ne s'appliquent pas vous aide à éviter les alertes inutiles et des résultats d'optimisation inexacts.

[[view-recommendations-for-configuration-issues]]
== Consultez les recommandations pour les problèmes de configuration

Vous pouvez consulter les recommandations relatives aux problèmes de configuration une fois l'analyse quotidienne terminée. Les recommandations expliquent les bonnes pratiques et les risques potentiels liés aux configurations non optimisées. Vous pouvez également télécharger un fichier CSV des recommandations.

.Étapes
. Connectez-vous au link:https://console.netapp.com/home["NetApp Console"^].
. Dans le menu NetApp Console, sélectionnez *Charges de travail* puis *Bien architecturé*.
. Depuis le tableau de bord Well-architected, sélectionnez *Afficher* pour toute configuration.
+
Vous pouvez également sélectionner image:button_download.png["Capture d'écran de l'icône de téléchargement"]pour télécharger un fichier CSV des recommandations pour toutes les configurations.

. Examinez la recommandation.




[[fix-a-configuration-issue]]
== Résoudre un problème de configuration

Vous pouvez corriger les problèmes de configuration d'un système Cloud Volumes ONTAP ou de volumes sélectionnés dans un système de fichiers. Vous pouvez sélectionner une ou plusieurs configurations à corriger.

Le processus de correction peut entraîner des indisponibilités d'instance ou des interruptions de service. Examinez attentivement chaque recommandation avant de corriger un problème de configuration.

.Étapes
. Connectez-vous au link:https://console.netapp.com/home["NetApp Console"^].
. Dans le menu NetApp Console, sélectionnez *Charges de travail* puis *Bien architecturé*.
. Depuis le tableau de bord Well-architected, sélectionnez *Afficher* pour toute configuration.
+
Assurez-vous de lire attentivement la recommandation. Cette recommandation explique les bonnes pratiques et les pièges potentiels des configurations non optimisées.

. Sélectionnez *Réparer* pour un seul volume ou *Afficher et réparer* pour plusieurs volumes. Pour plusieurs volumes, sélectionnez les volumes concernés à réparer.
. Consultez le résumé et les actions à entreprendre qui s'affichent dans la boîte de dialogue pour savoir ce qui se passe lorsque vous résolvez le problème. Certaines opérations peuvent entraîner des indisponibilités de l'instance ou des interruptions de service.
. Sélectionnez *Continuer* pour résoudre le problème de configuration.


.Résultat
Workload Factory lance le processus de résolution du problème. Sélectionnez le menu des paramètres du compte, puis *Tracker* pour consulter l'état de l'opération.



[[dismiss-a-configuration-analysis]]
== Rejeter une analyse de configuration

Interrompez l'analyse de configuration d'un système Cloud Volumes ONTAP ou de volumes sélectionnés. Vous pouvez relancer l'analyse si nécessaire.

[role="tabbed-block"]
====
.Rejeter une analyse de configuration pour un système
--
.Étapes
. Connectez-vous au link:https://console.netapp.com/home["NetApp Console"^].
. Dans le menu NetApp Console, sélectionnez *Charges de travail* puis *Bien architecturé*.
. Depuis le tableau de bord Well-architected, sélectionnez *Afficher* pour toute configuration.
. Dans la section Configurations, identifiez la configuration qui ne s'applique pas à votre environnement et sélectionnez ensuite *Ignorer*.
. Dans la boîte de dialogue de configuration « Ignorer », sélectionnez *Ignorer* pour arrêter l’analyse de configuration.


--
.Rejeter une analyse de configuration pour un volume
--
.Étapes
. Connectez-vous au link:https://console.netapp.com/home["NetApp Console"^].
. Dans le menu NetApp Console, sélectionnez *Charges de travail* puis *Bien architecturé*.
. Depuis le tableau de bord Well-architected, sélectionnez *Afficher* pour toute configuration.
. Sous Configurations, identifiez la configuration à ignorer pour les volumes sélectionnés, puis sélectionnez *View and fix*.
. Identifiez les volumes à exclure de l'analyse de configuration.
+
** Pour un seul volume : sélectionnez le menu Actions, puis sélectionnez *Ignorer le volume*.
** Pour plusieurs volumes : sélectionnez les volumes, puis sélectionnez *Ignorer* à côté de Bulk action.


. Sélectionnez *Ignorer* pour interrompre l'analyse de la configuration.
. Dans la boîte de dialogue Ignorer les volumes, sélectionnez *Ignorer* pour confirmer.


--
====
.Résultat
L'analyse de configuration s'arrête pour le système ou les volumes sélectionnés.

Vous pouvez réactiver l'analyse à tout moment.



[[reactivate-a-dismissed-configuration-analysis]]
== Réactiver une analyse de configuration rejetée

Réactivez à tout moment une analyse de configuration rejetée pour un système Cloud Volumes ONTAP. Vous pouvez sélectionner une ou plusieurs configurations à réactiver.

[role="tabbed-block"]
====
.Réactivez une analyse de configuration pour un système
--
.Étapes
. Connectez-vous au link:https://console.netapp.com/home["NetApp Console"^].
. Dans le menu NetApp Console, sélectionnez *Charges de travail* puis *Bien architecturé*.
. Sélectionnez *Configurations rejetées*.
. Identifiez la configuration que vous souhaitez réactiver et sélectionnez *Réactiver*.


--
.Réactiver une analyse de configuration pour un volume
--
.Étapes
. Connectez-vous au link:https://console.netapp.com/home["NetApp Console"^].
. Dans le menu NetApp Console, sélectionnez *Charges de travail* puis *Bien architecturé*.
. Sélectionnez *Configurations rejetées*.
. Identifiez le(s) volume(s) à réactiver à partir de l'analyse de configuration.
+
** Pour un volume : sélectionnez le menu Actions, puis sélectionnez *Réactiver le volume*.
** Pour plusieurs volumes : sélectionnez les volumes, puis sélectionnez *Réactiver* à côté de Bulk action.




--
====
.Résultat
Le système réactive l'analyse de configuration. Une nouvelle analyse a lieu chaque jour.
