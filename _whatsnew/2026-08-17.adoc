[[updated-configuration-names-in-the-well-architected-dashboard]]
=== Noms de configuration mis à jour dans le tableau de bord bien architected

Le tableau de bord bien conçu de NetApp Console inclut désormais de nouveaux noms de configuration de stockage.

Le tableau suivant répertorie les anciens noms de configuration et leurs nouveaux noms de configuration correspondants dans le tableau de bord bien architecturé.

[cols="1,1"]
|===
| Ancien nom de configuration | Nouveau nom de configuration 


| Planifiez les sauvegardes des volumes | Sauvegardes de volumes 


| seuil de capacité SSD | marge de capacité SSD 


| Seuil de capacité des fichiers | Marge de capacité des fichiers 


| Fiabilité des données de conservation à long terme | Étiquettes de politique de réplication 


| Instantanés locaux programmés | Stratégie de snapshot 


| Supprimez les sauvegardes inutiles | Expiration de la sauvegarde 


| Supprimer les instantanés inutiles | Expiration de l'instantané 


| Capacité SSD sous-utilisée | Capacité SSD surdimensionnée 


| Périphériques de bloc inactifs | Périphériques de blocs inactifs (LUN) 


| Optimisez le TCO en hiérarchisant les données froides | Hiérarchisation des données froides 


| Rapport de capacité logique de volume | Rapports de capacité visibles par l'hôte 


| FlexGroup volumes rééquilibrage | Rééquilibrer les volumes FlexGroup 


| FlexVol rééquilibrage des volumes | Rééquilibrer les volumes FlexVol 


| Mode d'écriture de la relation de cache | FlexCache mode d'écriture 


| Optimiser la taille du volume de cache | FlexCache taille de la réplique 


| Accès non autorisé au volume | Accès non autorisé au volume iSCSI 


| ARP/AI désactivé | Protection contre les ransomwares (ARP/IA) 
|===


[[well-architected-issues-displayed-in-netapp-console-systems-page]]
=== Problèmes bien architecturés affichés sur la page Systèmes de NetApp Console

Les notifications relatives aux problèmes d'architecture sont disponibles pour Cloud Volumes ONTAP dans Microsoft Azure depuis la page Systèmes de gestion du stockage dans la NetApp Console. Cette fonctionnalité vous aide à identifier rapidement les problèmes de configuration dans vos systèmes Cloud Volumes ONTAP dans Azure et à accéder au tableau de bord bien architecturé des charges de travail directement depuis la notification.
